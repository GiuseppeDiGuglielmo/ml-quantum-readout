# NN_0_770_prj

hls4ml project (Vivado backend, `io_stream`, ReuseFactor 1) for the model in `keras_model.h5`, input window 0-770 (1540 features). Generated in April 2024.

## Files not in git

- `NN_prj/`: Vivado HLS build output. Regenerate it with the scripts in this folder (`build_prj.tcl`).
- `tb_data/tb_input_features.dat` (1.8 GB): the test set `X_test_000_770.npy` written out as text, 101000 rows x 1540 values. The source array is on the NAS at `qick_data/<date>/000_770/X_test_000_770.npy` (see `data/README.md` and `data/link_data.sh`). The first 5000 and last 1000 rows were checked identical to the NAS array.
- `tb_data/tb_output_predictions.dat` and `tb_data/csim_results.log`: C simulation outputs, regenerated by running C simulation on the input above.
